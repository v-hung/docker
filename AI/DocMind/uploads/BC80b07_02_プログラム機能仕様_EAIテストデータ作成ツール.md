# 1. 概要

### 1. 概要

連係元IF外部設計書と連係先IF外部設計書の情報をもとに、単体テストで使用する入力テストデータと単体テスト仕様書を出力する。 現行でテストデータ作成ツール（EAIテストデータ作成ツール）と単体テスト仕様書作成ツール（単体テスト仕様書作成.xlsm）は別のツールであるが、どちらもIF外部設計書を インプットとしているため、 「単体テスト仕様書作成.xlsm」の機能を「EAIテストデータ作成ツール（Java）」に統合し、1つのJavaアプリケーションにする。

#### 1.2. 各ツール概要

##### 1.2.1 EAIテストデータ作成用Excel作成マクロ.xlsm

連係元外部設計書と連係先外部設計書から、EAIテストデータ作成ツールの入力となるEAIテストデータ作成用Excelを出力する。 [EAIテストデータ作成用Excelの出力仕様]

連係元外部設計書をベースにし、シート構成や内容は変更せず、同列に連係先外部設計書の対応する情報を追記する。 また、「データ構造」シートに各レコード単位の出力データ件数指定欄、「項目定義(№xx)」シートに各項目単位での固定値指定欄を追加する。

※詳細は 「補足. 現行マクロの説明」 参照

##### 1.2.2 EAIテストデータ作成ツール

EAIテストデータ作成用Excelと単体テスト仕様書を読み込み、 テストケースを自動決定し、単体テスト用入力データおよび単体テスト仕様書を作成する。 入力用テストデータの各レコードは、EAIテストデータ作成用Excelの出力データ数指定の件数分出力する。

|---|---|---|
| 実行環境 | Java25 / SpringBoot | ユーザにJarを配布 |
| UI | HTML | setting.ymlに画面から設定するためのフォーム、生成ボタン、エラー有無表示 |
| 設定管理 | setting.yml | 画面から設定された外部設定値の保管 |

# 2.1. 基本動作

### 2. 機能仕様

#### 2.1 基本動作

本ツールの処理の流れは、以下のとおり。 途中で処理に失敗した場合はエラーとし、以降の処理を行わない。

###### (1) EAIテストデータ作成用Excelの各シート取込

・概要・環境

連係方式（マッピング/パススルー）、文字コード、データ形式（可変長・固定長)、改行コード等を取得する。

・データ構造

レコード種別を判別する。

・項目定義

連係元および連係先の各項目の項目定義を取得する。

###### (2) 出力テストケース決定

(1)で取得した情報をもとに作成が必要なテストケースを決定する。 テストケースの決定条件は、「BC80e01_04_インタフェース基本テストケース.xlsx」参照。

###### (3) テストデータ出力

出力対象のテストケースについて、(1)で取得した項目定義仕様に基づいたデータを出力する。

###### (4) 単体テスト仕様書作成

仕様書の雛形Excelをベースに、(2)で決定したテストケースと、(1)で取り込んだEAIテストデータ作成用Excelに対応したテスト仕様書を出力する。

補足. 現行マクロの説明

#### (1) EAIテストデータ作成用Excel作成マクロ

EAIテストデータ作成ツールの入力となるEAIテストデータ作成用Excelを出力する。

・連係元外部設計書と連係先外部設計書をもとに作成する。 ・連係元外部設計書をベースにし、シート構成や内容は変更せず、連係先外部設計書の情報を追加する。 ・追加項目として、以下の入力欄を追加する。

-「データ構造」シート→各レコード単位での出力データ件数指定欄 -「項目定義(№xx)」シート→各連係元項目単位での固定値指定欄

###### [各シート内容]

|  | 内容 | 追加項目 |
|---|---|---|
| 変更履歴 |  | なし |
| 概要・環境 | 連係方式（マッピング/パススルー）、文字コード、データ形式（可変長・固定長)、改行コード等 | なし |
| データ構造 | レコードの構造 | 各レコード単位の出力データ件数を指定する欄をAU列に追加し、デフォルトで4を指定 |
| 項目定義(№xx) | 各レコードの項目定義
xxは通番 | 連係元項目に対応する連係先の項目情報を取得し、以下の情報をAU列以降に追記する。
（列：項目）
AU：固定値 / 属性、AV：ﾚｺｰﾄﾞNo、AW：項目No、AX：属性、AY：ﾊﾞｲﾄ数、AZ：符号、BA：整数桁数、BB：小数桁数、BC：ｴﾗｰ時動作、BD：Trim、BE：項目名（日本語）、BF：項目名（ID）、BG：編集詳細 |
